# Naveenkumar — Developer Portfolio

A responsive personal portfolio website built with HTML, CSS and JavaScript.

## What's included
- Intro and About section
- Education details
- Technical skills
- Academic projects
- Areas of interest
- Contact section
- Responsive mobile navigation, scroll progress and reveal animations

## Run locally
Open `index.html` in a web browser.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in the contact button with your professional email address.
- Replace the LinkedIn homepage link with your own LinkedIn profile URL.
- Review all education, skills and project details for accuracy.

## Technologies
HTML5 · CSS3 · JavaScript · Google Fonts
