# Naveenkumar — Developer Portfolio

A responsive personal portfolio built with HTML, CSS and JavaScript, featuring a procedural Three.js developer avatar and subtle interactive project-card effects.

## Portfolio sections

- Introduction and About
- Education history
- Technical skills
- Academic projects
- Learning and research interests
- Certifications and learning
- Contact links
- Dedicated resume page and downloadable PDF

## Design and accessibility

- Responsive layout and mobile navigation
- Dark, multi-tone software-development visual theme
- Animated 3D avatar with a profile-photo fallback
- Pointer-based project-card tilt on supported desktop devices
- Keyboard-visible focus styles and a skip-to-content link
- Reduced-motion support for animations and scrolling
- Project information remains readable without hover effects

## Run locally

Open `index.html` in a modern web browser. The 3D avatar loads Three.js from jsDelivr; if WebGL or the module cannot load, the page falls back to the profile portrait.

## Technologies

HTML5 · CSS3 · JavaScript · Three.js · Google Fonts
